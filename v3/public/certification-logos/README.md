# Certification provider marks

The AWS and Azure marks are local image assets from the [Amazon press center](https://press.aboutamazon.com/logos) and [Microsoft Azure icon announcement](https://azure.microsoft.com/en-us/blog/a-fluent-new-look-for-the-azure-icon/). Google Cloud and Apache Kafka marks are SVGs from the [Simple Icons project](https://github.com/simple-icons/simple-icons) converted to PNG for Word export. Simple Icons notes that individual icon licensing can vary; the provider marks remain their owners' trademarks.

These are provider marks, not credential-verification badges. The resume generator displays one only when a matching credential is present in the resume's `certifications` array and does not infer certification from skills or work history.
