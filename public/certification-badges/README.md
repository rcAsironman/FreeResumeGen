# Credential badge artwork

These local PNGs represent the credentials selected in the resume editor. AWS, Microsoft, and Google Cloud artwork is taken from the matching issuer badge pages hosted by Credly. The Confluent administrator and developer marks are certification badge artwork; the Confluent Cloud Operator selection uses the Confluent Certified Apache Kafka mark with its exact credential name in the selector.

The badge selector starts with the twelve credentials provided by the user and saves later selections in browser storage. Keep only credentials that are actually held on a resume.
